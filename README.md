# NS5119 獨立研究：校務研究與大數據分析（115-1）

國立中央大學 115 學年度第 1 學期獨立研究課程。以中央大學「2026 AI 校務治理實務競賽」為階段成果發表場域，從 NCU 校務研究（IR）資料出發完成一項校務研究專題。每週四 13:00–16:00，S5-601。
